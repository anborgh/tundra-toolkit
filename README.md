# Tundra Toolkit

Tundra Toolkit — расширение для форумных ролевых игр на MyBB/RusFF. Оно добавляет в браузер привычные инструменты: стикеры, черновики, личный игнор, счётчик постов и список активных эпизодов.

Все эти инструменты работают прямо из расширения на любом поддерживаемом форуме. Просить администратора установить отдельные скрипты не нужно — достаточно включить Tundra Toolkit в браузере.

Расширение меняет страницы только у вас: другие игроки этого не увидят. Отдельный аккаунт не нужен. Данные хранятся в браузере, а часть из них может синхронизироваться через Chrome Sync.

После установки откройте форум MyBB/RusFF и нажмите на значок расширения. Кнопка питания включает Tundra Toolkit на текущем форуме. На каждом форуме расширение нужно включать отдельно.

### Эпизоды

Собирайте активные темы с разных форумов в одном списке, смотрите новые ответы и вручную отмечайте «Мой ход». Если вы вышли из аккаунта или форум временно недоступен, тема останется в списке с пометкой «не обновляется».

### Стикеры

Собирайте свои стикерпаки из прямых ссылок на картинки. На странице с формой ответа стикер вставится как BBCode; если формы нет, расширение скопирует ссылку в буфер обмена. Вверху вкладки хранятся 6 недавно использованных стикеров.

### Черновики и шаблоны

Сохраняйте текст из формы ответа или создавайте шаблоны, которые удобно использовать несколько раз. Вставить сохранённый текст можно обратно в форму ответа.

### Игнор-лист

Скрывайте выбранных пользователей и темы только для себя. Игнор пользователей действует в рамках выбранного раздела: например, можно скрыть человека во флуде и оставить его в игровом разделе. Скрытое можно временно показать, не удаляя записи из списка.

### Счётчик постов

Выберите разделы, пользователей и период — Tundra Toolkit посчитает посты и покажет результат, в том числе в BBCode.

### Стиль

На вкладке «Стиль» можно включить «SFW-стиль», изменить размер текста, настроить красную строку и интервалы между абзацами. SFW-стиль меняет только оформление и не проверяет содержимое постов.

### Безопасность

Включайте Tundra Toolkit только на форумах, которым доверяете. Не храните в черновиках пароли, токены доступа, резервные коды, платёжные и паспортные данные или приватные переписки.

Chrome Sync — не резервная копия. Если места не хватает, данные остаются в текущем браузере и могут исчезнуть при очистке данных, удалении профиля или расширения. Важные тексты сохраняйте отдельно.
